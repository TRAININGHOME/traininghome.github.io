Ficha Técnica del Prototipo

Esta versión estática demuestra la arquitectura de MANTRA, consumiendo datos en tiempo real de una API dinámica.

Frontend Estático

Plataforma: GitHub Pages

Tecnologías: HTML5, CSS3 (Glassmorphism), JavaScript (Fetch API).

Esta es la interfaz de usuario que presenta el proyecto y se conecta al backend dinámico.

Backend Dinámico

Plataforma: Render

Tecnologías: Node.js, Express, Cors.

Una API RESTful que procesa las peticiones y gestiona la lógica de conexión a la base de datos.

Base de Datos

Plataforma: Neon Tech

Tecnologías: PostgreSQL Serverless.

Almacenamiento persistente y estructurado para usuarios, eventos y calificaciones.
